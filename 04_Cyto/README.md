# Cytoscape Network Visualization Directory (`04_Cyto`)

This directory contains the core node and edge tables generated by the pan-network and item-set relationship analysis script. These files are specifically structured for hierarchical network visualization, multi-tier module tracking, and structural topology exploration in **Cytoscape**.

---

## ⚙️ Generation Script

* **[Cyto.R](./Cyto.R)**: The core data preprocessing and network transformation engine. It parses multi-level module relationships (`clustid2Module2Step.RDS`), calculates overlapping gene intersections between modules across different analytical steps, performs hierarchical grouping, filters out redundant/unchanged modules, and outputs the final structured tables required for Cytoscape visualization.

---

## 📂 Included Files Description

* **[Module(Cyto)_relation_node.txt](./Module(Cyto)_relation_node.txt)**
  * **Description:** The comprehensive pan-network module node table. It compiles metadata for each filtered network module (e.g., `Id`, `Clustid` containing member gene IDs, `Module_size`, `Module_type`, and assigned `Group` categories based on hierarchical mapping between Step 1 and Step 3).
  * **Purpose:** Serves as the primary node attribute source in Cytoscape, allowing users to map module sizes, types, and group affiliations after removing redundant/unchanged modules.

* **[Module(Cyto)_relation_edge.txt](./Module(Cyto)_relation_edge.txt)**
  * **Description:** The hierarchical pan-network edge table defining the relationships between modules (`Source` and `Target`). It records interaction properties such as `Edge_type` (e.g., *Normal* or *Self_loop*), individual module sizes (`Source_size`, `Target_size`), and the calculated directional size proportion (`Source2Target_ratio`).
  * **Purpose:** Serves as the edge attribute source in Cytoscape to visualize multi-level module inclusion, hierarchical transitions, and overlap dynamics across different analytical steps.
