# Cytoscape Network Visualization Directory (`04_Cyto`)

This directory contains the formatted node and edge tables specifically designed for network visualization, modular layout, and topological exploration using **Cytoscape**.

---

## 📂 Included Files Description

* **[Module(Cyto)_relation_edge.txt](./Module(Cyto)_relation_edge.txt)**
  * **Description:** The comprehensive network edge table containing pairwise or hyperedge connections, interaction types (e.g., regulatory relationships, hyperedge links), F-scores, and edge weights (such as median Universality).
  * **Purpose:** Acts as the edge attribute source for importing network topologies and defining connection styles in Cytoscape.

* **[Module(Cyto)_relation_node.txt](./Module(Cyto)_relation_node.txt)**
  * **Description:** The comprehensive network node table containing node IDs, functional classifications, module assignments, size metrics, and custom visual color mappings.
  * **Purpose:** Serves as the node attribute source for mapping visual properties (such as node size, shape, and color annotations for Regulons, Operons, and modules) within Cytoscape.
