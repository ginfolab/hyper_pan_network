# Visualization and Figure Generation Scripts (`02_figures`)

This directory contains all R scripts used to generate the main manuscript figures, supplementary charts, and formatted tables for the *E. coli* pan-transcriptomic hypergraph project. 

---

## 📊 1. Main Figures

* **[Figure 2- Figure S3 .R](./Figure%202-%20Figure%20S3%20.R)**: Generates the core network organization charts and associated comparative landscapes presented in Main Figure 2 and Supplementary Figure S3.
* **[Figure 4. Hyperedge sharing and functional：regional characterization of the module-group.R](./Figure%204.%20Hyperedge%20sharing%20and%20functional%EF%BC%9Aregional%20characterization%20of%20the%20module-group.R)**: Analyzes hyperedge sharing patterns and provides functional and regional characterizations of module groups for Main Figure 4.

---

## 📈 2. Supplementary Figures

* **[Figure S1.R](./Figure%20S1.R)**: Generates foundational overview charts and basic dataset statistical distributions for Supplementary Figure S1.
* **[Figure S5. Functional connectivity network of 16 representative modules.R](./Figure%20S5.%20Functional%20connectivity%20network%20of%2016%20representative%20modules.R)**: Computes and visualizes the functional connectivity networks across 16 representative network modules (Supplementary Figure S5).
* **[Figure S6. Comparative size distribution of identified network communities and Regulon.R](./Figure%20S6.%20Comparative%20size%20distribution%20of%20identified%20network%20communities%20and%20Regulon.R)**: Visualizes the comparative size distributions between identified network communities and reference Regulon structures (Supplementary Figure S6).
* **[Figure S7 Relationship between the double-ring pie chart statistics module and regulonD.R](./Figure%20S7%20Relationship%20between%20the%20double-ring%20pie%20chart%20statistics%20module%20and%20regulonD.R)**: Generates double-ring pie chart statistics mapping network modules to RegulonDB annotations (Supplementary Figure S7).
* **[Figure S8. Transcriptional status of the E. coli functional architecture across network cla.R](./Figure%20S8.%20Transcriptional%20status%20of%20the%20E.%20coli%20functional%20architecture%20across%20network%20cla.R)**: Maps and illustrates the condition-specific transcriptional status of the functional architecture across network clades and regions (Supplementary Figure S8).
* **[The latest Figure S9, the Sankey diagram, illustrates the relationship between subregion.R](./The%20latest%20Figure%20S9,%20the%20Sankey%20diagram,%20illustrates%20the%20relationship%20between%20subregion.R)**: Constructs a Sankey flow diagram illustrating the dynamic mapping relationships and transitions between subregions and functional states (Supplementary Figure S9).
* **[Figure S10 and S11 - Statistical module for edge distribution in any dataset.R](./Figure%20S10%20and%20S11%20-%20Statistical%20module%20for%20edge%20distribution%20in%20any%20dataset.R)**: Computes and plots statistical distributions of network edges across diverse transcriptomic datasets.
* **[S11. Combined density of heat maps and stacked charts with accompanying diagrams.R](./S11.%20Combined%20density%20of%20heat%20maps%20and%20stacked%20charts%20with%20accompanying%20diagrams.R)**: Combines kernel density heatmaps and stacked proportion charts into a unified multi-panel visualization.
* **[The U distribution of the module.R](./The%20U%20distribution%20of%20the%20module.R)**: Analyzes and visualizes the Universality ($U$) score distributions across network modules.

## 📋 3. Supplementary Tables & Data Processing

* **[Table1 and Table3 and annotation Module Group Region.R](./Table1%20and%20Table3%20and%20annotation%20Module%20Group%20Region.R)**: Generates and formats Table 1 and Table 3, integrating precise functional annotations for module groups and regional classifications.
* **[Table 2 Processing of the latest GSE sort file.R](./Table%202%20Processing%20of%20the%20latest%20GSE%20sort%20file.R)**: Parses, sorts, and organizes GSE metadata and sample sorting criteria required for Table 2.
* **[The production process of Table 5.R](./The%20production%20process%20of%20Table%205.R)**: Executes the complete end-to-end data compilation and formatting workflow for Table 5.
